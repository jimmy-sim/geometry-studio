# geometry-studio

A browser-based tool for creating animated mathematical art with Gleam.

**[Try the live app](https://jimmy-sim.github.io/geometry-studio/)**

## Features

- Write and edit Gleam programs with live drawing updates.
- Draw lines, circles, and cubic Bézier curves.
- Explore rotational symmetry, reflections, and color palettes.
- Control animation speed, pause, and reverse playback.
- Save named drawings in your browser.
- Export finished artwork as SVG.

To get started, click **Petal Observatory**, then experiment with the shape, symmetry, and color controls.

## About

Built as an extension of UC Berkeley’s CS 61A Animator project, connecting my interests in programming and mathematical visualization.

I implemented the course’s core interpreter exercises and developed the interface and Geometry Studio extension with AI coding assistance. The application builds on the course-provided Gleam and Lustre framework.

This repository contains the compiled web app deployed through GitHub Pages.
