# geometry-studio

A browser-based tool for creating animated mathematical art with Gleam.

**[Try the live app](https://jimmy-sim.github.io/geometry-studio/)**

## Features

- Edit Gleam programs and see drawings update live.
- Draw lines, circles, and cubic Bézier curves.
- Explore rotational symmetry, reflections, and color palettes.
- Play, pause, reverse, and adjust animation speed.
- Save named drawings in your browser.
- Export finished artwork as SVG.

Click **Petal Observatory** to explore an example, then experiment with the shape, symmetry, and color controls.

## About

Created for UC Berkeley’s CS 61A Animator project, combining programming with mathematical visualization. Built with Gleam and Lustre on the course-provided framework.

This repository contains the compiled web app deployed through GitHub Pages.
